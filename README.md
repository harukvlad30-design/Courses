# Courses — Облік пройдених курсів

**Тема проєкту:** Облік пройдених курсів: курси, платформи, сертифікати; обсяг навчання за періодами (Тема № 22).

Застосунок призначений для систематизації та ведення персонального обліку онлайн- і офлайн-навчання. Він дозволяє зберігати інформацію про пройдені освітні курси, навчальні платформи та отримані сертифікати, а також аналізувати загальний обсяг витрачених годин навчання за обраними часовими періодами. Проєкт орієнтований на студентів, ІТ-фахівців та всіх, хто займається самоосвітою і прагне відстежувати свій професійний розвиток.

## Особливість проєкту

Як додаткову функціональність проєкту обрано **експорт звіту у файл із роздільниками (CSV) для подальшого опрацювання**. Ця можливість дозволить користувачеві одним натисканням вивантажити сформовану вибірку пройдених курсів, витрачених годин та отриманих сертифікатів за обраний період у табличний файл формату CSV. Це необхідно для зручного зберігання резервної копії освітнього портфоліо, побудови власних графіків в Excel або передачі звіту про підвищення кваліфікації роботодавцю чи в навчальний заклад.
